# AI usage

OpenAI Codex assisted with source review, competitive research, implementation, regression tests, CLI improvements, documentation and analysis of saved measurements in this working session. The user directed the scope and requested manual GitHub submission. AI assistance does not establish correctness, novelty or security.

The repository includes substantial upstream sidecar and workshop code. See [upstream provenance](docs/UPSTREAM.md) and preserve upstream licenses. Supplied competitor READMEs and organizer messages were used as context; competitors were not fully audited and supplied messages were not independently authenticated.

Build/test outcomes and experiments are recorded separately in the hardening validation report. Synthetic fixtures, recorded devnet evidence and new private-chain measurements must not be represented as production verification. The human submitter should review the final changes and this disclosure before submission, and complete any additional ETHGlobal disclosure requirements.
